# CropGuard Client

אפליקציית הרשת של CropGuard: React 19 + JavaScript (JSX) + Tailwind CSS 4 + Vite.
בעברית מלאה ומימין לשמאל, ומותאמת לטלפון בשדה.

## הרצה

דרושים שרת הליבה (`apps/server`, פורט 3000) ושירות ה-AI (פורט 8001). מהתיקייה הראשית:

```powershell
npm run dev:ai       # בטרמינל אחד
npm run dev:server   # בטרמינל שני
npm run dev:client   # בטרמינל שלישי
```

האפליקציה נפתחת ב-`http://localhost:5173`.
כתובת השרת נקבעת ב-`VITE_API_URL` (ברירת מחדל `http://localhost:3000/api`; ראו `.env.example`).

## המסכים

| נתיב | מסך |
|---|---|
| `/login`, `/register` | התחברות והרשמה (חקלאי או אגרונום, טלפון לא חובה), עם JWT מול שרת הליבה |
| `/forgot-password` | שחזור סיסמה בשני שלבים: טלפון -> קוד ב-SMS + סיסמה חדשה |
| `/scan` | **המסך המרכזי**: בחירת חלקה, העלאת תמונת עלה, ספינר, וכרטיס התוצאה |
| `/fields` | החלקות (אגרונום רואה של כולם, עם שם הבעלים) והוספת חלקה, כולל מילוי לפי המיקום |
| `/history` | היסטוריית אבחונים עם סינון לפי חלקה ולפי מצב, טעינת עוד, ומחיקה עם אישור |
| `/library` | ספריית 38 המצבים: כרטיסיות, חיפוש, סינון לפי גידול וסוג גורם, וחלון פרטים עם תסמינים, מניעה ומחירים |
| `/news` | חדשות חקלאות ומדע מהארץ ומהעולם, עם סינון לפי שפה |
| `/account` | פרטי החשבון והוספת טלפון לשחזור סיסמה |

### כרטיס התוצאה

מעוצב כ"תווית דגימה":
- פס סטטוס אדום (נגוע) או ירוק (בריא).
- שם המחלה בעברית בגדול, השם באנגלית, והשם המדעי בנטוי (כמקובל בבוטניקה).
- מד ודאות עם סימון של סף 50%.
- הנחיית טיפול בעברית.
- חומרים פעילים, והראשון מסומן "מומלץ".
- מוצרים עם טווחי מחירים בשקלים, על סקאלה משותפת כדי להשוות במבט אחד.

## מערכת העיצוב

| | |
|---|---|
| צבעים | נייר `#F4F6F1`, דיו `#1D2B22`, כלורופיל `#2F6B3F` (פעולות), קש `#E3B23C` (אזהרות ומחירים), כימשון `#A8382B` (נגוע), אדמה `#6B5B47` (טקסט משני) |
| גופנים | Frank Ruhl Libre (כותרות ושמות מחלות), IBM Plex Sans Hebrew (ממשק), IBM Plex Serif Italic (שמות מדעיים בלבד). נטענים מקומית, בלי בקשות לגוגל |
| RTL | `dir="rtl"` על כל המסמך, מאפיינים לוגיים (`start`/`end`), ובידוד `<bdi dir="ltr">` למספרים, מחירים ושמות באנגלית |
| נגישות | מיקוד מקלדת בולט, `<meter>` אמיתי למד הוודאות, תוויות לכל שדה, כבוד ל-`prefers-reduced-motion` |

הטוקנים מוגדרים ב-`src/index.css` (`@theme`).

## מבנה

| תיקייה | תוכן |
|---|---|
| `src/api/client.js` | כל הקריאות לשרת, עם JWT, והודעות שגיאה בעברית |
| `src/auth/AuthContext.jsx` | מצב ההתחברות; טוקן שפג מנתק אוטומטית |
| `src/components/` | כרטיס התוצאה, מד הוודאות, בוחר התמונה, המסגרת והניווט, רכיבי טופס |
| `src/pages/` | המסכים |
| `src/lib/` | עיצוב מחירים, אחוזים ותאריכים בעברית, ושמות גידולים |
| `src/test/` | הגדרות הבדיקות וכלי עזר (fetch מדומה, נתוני דוגמה) |

צורות הבקשות והתשובות מתועדות ב-`@cropguard/shared-types` (JSDoc). שינוי בשרת נתפס בבדיקות של הלקוח, שבודקות את המסכים מול תשובות לדוגמה.

## בדיקות ואיכות

```powershell
npm test            # 94 בדיקות (Vitest + Testing Library)
npm run lint        # oxlint, כולל חוקי React Hooks ונגישות
npm run build       # בנייה לייצור
```

הבדיקות מרנדרות את המסכים האמיתיים עם `fetch` מדומה. הן לא צריכות שרת.

> **למה oxlint ולא ESLint?** oxlint מהיר מאוד, לא צריך קובץ הגדרות, ובודק את אותם חוקי React Hooks ונגישות.
> בלי בדיקת טיפוסים, הוא גם מה שתופס משתנים וייבואים שלא בשימוש.
